乘法心算策略

两位数乘法不只有一种做法。下图展示了几种常用的心算策略：拆成十位和个位、先凑整再调整、用减法修正，以及用数轴来思考。

1. 把数字拆成容易计算的部分

例如 23 x 47，可以把 23 看成 20 + 3，把 47 看成 40 + 7。然后分别计算 20 x 40、20 x 7、3 x 40、3 x 7，让两位数乘法变成几个简单步骤。

2. 先凑整，再调整

有些数字接近整十数时，可以先凑整。比如 46 x 38 可以看成 (50 - 4) x (40 - 2)。先用容易计算的数，再把多出来或少掉的部分调整回来。

3. 根据数字选择方法

如果数字接近 30、40、50，凑整通常更快。如果两个数字都比较普通，拆成十位和个位更稳定。可以在 Mentalc 中反复练习这些心算方法。
