Cara menghitung perkalian dan pembagian satu digit

Perkalian dan pembagian satu digit lebih mudah jika dilihat sebagai kelompok yang sama. Ini membantu memahami tabel perkalian dan pembagian dasar.

1. Lihat perkalian sebagai kelompok sama

3 x 3 berarti tiga kelompok berisi tiga. Gambaran ini membuat perkalian terasa lebih konkret.

2. Hubungkan titik dengan tabel perkalian

Jika ada 4 kelompok berisi 3 titik, hitung 3, 6, 9, 12. Pola ini menjadi shortcut mental math.

3. Lihat pembagian sebagai berbagi sama rata

Jika 12 titik dibagi menjadi 3 kelompok sama, setiap kelompok berisi 4. Ini menghubungkan pembagian dengan perkalian.

4. Latih dua arah

Pasangkan fakta: 3 x 4 = 12, lalu 12 ÷ 3 = 4. Latihan singkat membuat pola lebih cepat muncul.
